
# Sakura Midnight — Windows Terminal

A custom dark theme with soft sakura pink, muted lavender, warm cream, and subtle botanical accents.

## Installation

1. Open Windows Terminal.
2. Open Settings.
3. Select **Open JSON file**.
4. Copy the contents of `sakura-midnight.json`.
5. Add the theme object inside the existing `"schemes"` array.
6. Save the file.
7. Open your profile's Appearance settings.
8. Select **Sakura Midnight** under Color scheme.

Do not replace your entire settings file.
